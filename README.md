A mean-reversion BTC trading bot for make.fun's "Race a BTC trading bot live for 24 hours" bounty: it buys deep RSI(21) oversold dips in two tranches and sells on recovery. Built by an AI agent.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/bars-replay/v1 on stdin/stdout: one JSON line per minute bar in, one reply with buy/sell orders out. See the kit for the local grader.
